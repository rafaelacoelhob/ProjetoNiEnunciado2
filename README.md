
##  Projetos Desenvolvidos

###  1. Sistema de Compras com CheckBox
- O usuário seleciona produtos de mercado (arroz, leite, carne, etc.) usando **CheckBoxes**.
- Ao clicar em "Calcular Total", o app mostra o valor total da compra.
- Utiliza: `CheckBox`, `Button`, `TextView`.

###  2. Reajuste Salarial com RadioButton
- O usuário digita seu salário e escolhe o percentual de reajuste (40%, 45% ou 50%).
- O novo salário é calculado e exibido.
- Utiliza: `EditText`, `RadioGroup`, `RadioButton`, `Button`, `TextView`.

###  3. Cadastro de Clientes - Tem de Tudo
- App com **3 Activities**:
  1. Tela de boas-vindas com logotipo.
  2. Formulário com `TextInputLayout` para o nome.
  3. Tela de confirmação com mensagem dinâmica e botão para voltar.
- Utiliza: `Intent`, `TextInputLayout`, `ImageView`, `TextView`, `Button`.

###  4. Lanche Fácil - Registro de Pedidos
- App com 3 telas:
  1. Tela inicial com logomarca.
  2. Formulário com nome e seleção de lanche.
  3. Tela de resumo com dados do pedido e botão de retorno.
- Utiliza: `TextInputLayout`, `Button`, `TextView`, `Intent`, `ImageView`.

###  5. Simulador de Pedidos em Pizzaria
- App dividido em 3 atividades:
  1. Seleção de sabores via `CheckBox`.
  2. Escolha do tamanho e pagamento com `RadioGroup`.
  3. Tela de resumo com detalhes e valor total.
- O valor é calculado com base na combinação de sabores e tamanho.
- Utiliza: `CheckBox`, `RadioButton`, `Intent`, `TextView`, `Button`.

- Android Studio
